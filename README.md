# DT InDesign Scripts

Скрипты для InDesign Scripts Panel.

Обновление: запусти Update-DT-Scripts.bat (Windows) или Update-DT-Scripts.command (macOS).
Файлы ставятся в отдельную папку **Design Terminal Git** — другие скрипты не трогает.

macOS, первый запуск: правый клик → Open (Gatekeeper). Админ-права не нужны.
Если «Permission denied»: в Terminal выполни `chmod +x Update-DT-Scripts.command` и снова Open.

В наборе:
- TerminalPreparator
- LegalParagraphSetup
- ImageCroper
- ImageLinkSyncer
- SaveAsInddAndIdml
- TerminalBelarusPreparator

# DT InDesign Scripts

Scripts for the InDesign Scripts Panel.

Update: run Update-DT-Scripts.bat (Windows) or Update-DT-Scripts.command (macOS).
Files go into a separate folder **Design Terminal Git** — other scripts are left alone.

macOS first launch: right-click → Open (Gatekeeper). No admin rights.
If “Permission denied”: run `chmod +x Update-DT-Scripts.command` in Terminal, then Open again.

Included:
- TerminalPreparator
- LegalParagraphSetup
- ImageCroper
- ImageLinkSyncer
- SaveAsInddAndIdml
- TerminalBelarusPreparator
